Tools

Operators bring the signal. The owner keeps the eval set, the base model and the gate.

Owner only

TakesGives

Signal

  • Grounding Takes documents Gives context, retrieved at answer time
  • Policies Takes rules, in plain words Gives a constraint on every answer
  • Demonstrations Takes input and output pairs Gives training rows, three per new pair
  • Corrections Takes an answer from the Playground, fixed or marked good Gives a demonstration
  • Interviews Soon Takes an operator’s answers to the model’s questions Gives facts and rules it answers from

Training

  • Eval set Owner only Takes prompts, each with what a passing answer must contain Gives a pass rate, before and after every run
  • Base model Owner only Takes Heura Arche (2B), or a model you bring Gives the model that answers
  • Fine-tune Takes new demonstrations and corrections, plus a replay mix Gives a LoRA checkpoint on Heura Arche
  • OpenAI fine-tune Owner only Takes the same rows Gives a fine-tuned OpenAI model

Release

  • Promotion gate Owner only Takes a run’s checkpoint Gives the live checkpoint, unless it scores lower
  • Serving Takes the live checkpoint Gives an OpenAI-compatible endpoint, an embed, an export

Specifications

Base model
Heura Arche, 2B, built on Qwen3-VL-2B-Instruct. Or a model you bring: Claude, GPT, Gemini, or any model behind an OpenAI-compatible server.
Training
Supervised fine-tuning: LoRA adapters on Heura Arche, or OpenAI’s fine-tuning API for its fine-tunable models.
Training data
Your demonstrations and corrections, plus a replay mix of Heura’s own data so the base keeps its general skills. Answers written by Claude, GPT or Gemini never enter a training set.
Evaluation
Every run is scored on the eval set before and after it trains.
Promotion
A checkpoint that scores lower than the live one is held back. Only the owner can promote it by hand.
Serving
An OpenAI-compatible endpoint, /v1/chat/completions and /v1/models, and an embed for websites.
Export
The active adapter, with a runtime that has an OpenAI-compatible server, the Apache-2.0 licence and a NOTICE for Qwen.
Access
The owner keeps the base model, the eval set, promotion, keys and exports.
