The sequence

Operators produce the signal. The ML team owns the base model, the eval set and the gate.

  1. Ground

    Attach documents. Retrieval grounds each answer in them.

  2. Set policies

    Rules applied to every answer.

  3. Demonstrate

    Input and output pairs: the supervised fine-tuning data.

  4. Correct

    Fix an answer in the Playground. The correction becomes a training row.

  5. Evaluate

    An eval set of prompts, each with what a passing answer must contain. The result is a pass rate. Only the owner changes the eval set.

  6. Train

    Supervised fine-tuning: a LoRA adapter on Heura Arche, or OpenAI’s fine-tuning API. A replay mix rides along so the base keeps its general skills. The eval set runs before and after.

  7. Promote

    The new checkpoint replaces the live one, unless it scores lower. A tie promotes. The owner can also promote one by hand.

  8. Serve

    An OpenAI-compatible endpoint, an embed for your website, or an export: the adapter and a runtime.

What it does, and what it doesn’t yet

It does

  • Evaluates every run before and after it trains.
  • Holds back a run’s checkpoint that scores lower on the eval set than the live one. Only the owner can promote it by hand.
  • Trains LoRA adapters on Heura Arche, a 2B model built on Qwen3-VL-2B-Instruct, and runs supervised fine-tuning on OpenAI’s fine-tunable models.
  • Builds training rows from your demonstrations and corrections, plus a replay mix of Heura’s own data so the base keeps its general skills. Answers written by Claude, GPT or Gemini never enter a training set.
  • Serves an OpenAI-compatible endpoint: /v1/chat/completions and /v1/models.
  • Exports the active adapter with a runtime that has an OpenAI-compatible server, the Apache-2.0 licence and a NOTICE for Qwen.
  • Answers with a base model you bring: Claude, GPT, Gemini, or any model behind an OpenAI-compatible server.
  • Keeps the base model, the eval set, promotion, keys and exports with the owner.

It doesn’t, yet

  • Reinforcement learning or preference optimization. Training is supervised fine-tuning.
  • Training a base model you bring, except OpenAI’s fine-tunable models.
  • Sizes above 2B. Heura Arche is the one available.
  • SOC 2, VPC or on-premises deploys. Export, which runs the model on your own machine, is the self-hosted option.
  • Held-out evals. Nothing stops an eval prompt from also being a demonstration.
