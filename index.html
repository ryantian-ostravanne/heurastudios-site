Specifications

Base model
Heura Arche, 2B, built on Qwen3-VL-2B-Instruct. Or a model you bring: Claude, GPT, Gemini, or any model behind an OpenAI-compatible server.
Training
Supervised fine-tuning: LoRA adapters on Heura Arche, or OpenAI’s fine-tuning API for its fine-tunable models.
Training data
Your demonstrations and corrections, plus a replay mix of Heura’s own data so the base keeps its general skills. Answers written by Claude, GPT or Gemini never enter a training set.
Evaluation
Every run is scored on the eval set before and after it trains.
Promotion
A checkpoint that scores lower than the live one is held back. Only the owner can promote it by hand.
Serving
An OpenAI-compatible endpoint, /v1/chat/completions and /v1/models, and an embed for websites.
Export
The active adapter, with a runtime that has an OpenAI-compatible server, the Apache-2.0 licence and a NOTICE for Qwen.
Access
The owner keeps the base model, the eval set, promotion, keys and exports.
